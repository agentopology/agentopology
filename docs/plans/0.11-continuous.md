Every lens reads the projection (`project.ts`) and the embedded facts (`facts.ts`); none adds a second copy of a field. - **VZ-5 Flow lens.** Gates and the guards that cite them are chips on the edges they sit on; human decision points sit in one "seat" lane; stores sit on a rail with read and write ticks; jobs and triggers carry flags; loop, wait and error edges have distinct styles (dash pattern and a word, not only color); stages are collapsed on open. Done when: `kitchen-sink.at` opens with at most 25 blocks drawn at 1440 by 900, labels at least 11 px, and 0 overlapping node boxes (planted test computes box overlaps from the drawn svg).
- **VZ-6 Sessions lens.** Places are titled boxes; session agents sit in their place with their subagents nested; talk edges carry the message kind as a chip; `talk: hub` draws as a hub; a session with no talk guard on disk shows an "unguarded" hatch; `decides:` shows a badge; send and spawn guard grades from the facts. Done when, on `session-ops.at`: a test can read from the page data alone which sessions may message which (matching the talk edges the binding compiles) and which session decides each declared decision.

- **VZ-10 Index and embedded source.** Every item as one row with its source line; the `.at` text embedded with line anchors (escaped with the existing `jsonForScript` rules); clicking a row jumps to its line. Done when every node id in the projection has an index row whose line number matches the parser's, on every file in `examples/`.
